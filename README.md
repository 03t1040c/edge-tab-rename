# Tab Trim

Edgeのタブタイトルから、登録した不要ワードを削除するManifest V3拡張機能です。専用アイコンを常時ツールバーに表示する必要はありません。

## Edgeで使う

1. Edgeで `edge://extensions` を開く。
2. 「開発者モード」をオンにする。
3. 「展開して読み込み」を選び、このREADMEとmanifest.jsonのあるフォルダを指定する。
4. 初回に開く設定タブで不要ワードを入力して「追加する」。

設定画面は拡張機能の詳細から「拡張機能のオプション」で開けます。拡張機能メニューからアイコンをクリックして開くこともできます。アイコンをツールバーに固定する必要はありません。任意のキーボードショートカットも `edge://extensions/shortcuts` で割り当てられます。

## 動作

- URL条件は空欄が標準。すべてのアクセスを許可されたHTTP/HTTPSページに適用します。
- ワードは大文字・小文字、半角・全角、スペースを区別した完全な文字列一致です。前後のスペースも保存します。正規表現としては扱いません。
- 元タイトルに含まれる一致部分をまとめて削除。同じ位置で複数ワードが重なるときは長いワードを優先します。削除によって新たにつながった文字列は再削除しません。
- 空白だけのタイトルになる場合は、元タイトルを残します。周囲の空白や区切り記号を勝手に削除しません。
- 任意のURL条件は同一オリジンの指定パスと配下に適用します。`/sites/sales` は `/sites/sales2` に一致しません。クエリやフラグメントを指定した場合、その部分も完全一致で判定します。
- 追加・変更は自動保存され、既存タブにも反映されます。ルール停止・削除時は最新の元タイトルへ戻します。
- プレビューは開いているタブの元タイトルを読み込み可能。半角／全角スペースとタブ文字を表示用の印で区別します。入力中の未保存ワードも試せます。
- テストするタイトルの入力欄で文字を選択すると、実際の空白を保ったまま不要ワード欄に取り込めます。
- ルールは500件、各ワードは2048文字までです。

## 軽さと追従

タイトル要素と、その交換を検知するためのhead／htmlの直下のみを監視します。ページ本文全体の監視、定期巡回、定期通信は行いません。変更通知は40ms単位にまとめ、自身のタイトル書き換えは監視対象から一時的に外して再帰処理を防ぎます。ルールが空または全停止ならDOM監視を解除します。

ページ側のタイトル再設定、title要素の交換、通常遷移、履歴APIによるURL変更、ページ復帰に対応します。短時間のタイトル差し戻りが画面に見える可能性はあります。サイトが継続してタイトルを変更する場合はその変更に応じた処理負荷が発生します。

## 制限

Edge内部ページ、拡張機能ストアなどブラウザーが変更を禁止するページは対象外です。PDFビューアー等の特殊ページも対象外になる場合があります。組織のEdge管理ポリシーやサイトアクセス設定によって動作が制限される場合があります。

拡張機能を再読み込み・更新した後、既存ページで反映されない場合はページを再読み込みしてください。停止・削除の設定変更ではページの再読み込みは不要です。

## 検証と配布

`node --test tests/rules.test.cjs` で文字列変換とURL条件を検証できます。ブラウザー検証にはPlaywrightが必要です。

PowerShellから `.\tools\package.ps1` で `dist/tab-trim-1.0.3.zip` を作成します。パッケージには実行に必要なファイルだけを含みます。ビルドにはNode.jsを使用しますが、拡張機能の利用には不要です。

公開用のプライバシーポリシーHTMLは `node tools/prepare-store.cjs` で `store-assets/privacy.html` と `docs/privacy.html` に生成します。GitHub Pagesはmainブランチの `/docs` を公開対象にできます。申請用の画像・説明・審査用メモは `store-assets/` にあります。

`node tools/check-release.cjs` で日本語の掲載情報・依存ファイル・画像サイズ・ポリシーの一致を確認できます。パッケージ作成時にも自動実行します。

Microsoft Edge Add-onsへの登録操作は `PUBLISH.md`、申請欄の説明と素材一覧は `STORE.md` を参照してください。実際のSPO環境での確認状況は、このプロジェクトの自動テスト結果とは別に判断してください。
